# Poetic Cybermetrics — 詩のサイバメトリクス

**Poetic Waveform Analytics**

このリポジトリは、詩を「数値化」して波形として可視化する実験的プロジェクトです。  
詩行ごとの **Divergence（詩的跳躍度）** を埋め込みモデルを用いて計算し、  
Streamlit アプリでインタラクティブに分析・描画できます。

---

## 公開中の Streamlit アプリ

このリポジトリから、以下の **2種類のアプリ** を公開しています：

1. **単一モデル版**  
   [poetic-waveform-analytics-divergence.streamlit.app](https://poetic-waveform-analytics-divergence.streamlit.app/)

   * SBERT 系モデル（英語寄り / 多言語対応）
   * 入力テキストの Divergence 波形を描画
   * 参照は直前 k 行（k 任意）

2. **４モデル比較版**  
   [poetic-waveform-analytics-divergence-4models.streamlit.app](https://poetic-waveform-analytics-divergence-4models.streamlit.app/)

   * SBERT（英語寄り / 多言語対応）
   * OpenAI Embeddings（small / large）
   * Ruri-v3-30m（日本語特化）
   * ４モデルの波形を比較・重ね描画
   * CSV（**wide形式**）出力に対応
   * 参照は直前3行（k=3固定）

## 背景

このプロジェクトは「詩の数値化／Poetic Cybermetrics」をテーマにしています。  
従来の詩学や批評を補完する新しい方法として、  
詩を埋め込みベクトル空間に写像し、その文脈からの逸脱度を波形として可視化します。

* **Divergence（逸脱度／詩的跳躍度）**
* **Resonance（共鳴度／余韻）※現在は試行中**

これらの指標を通じて、詩の実作における **主観的な感覚（内観）をより鋭敏に捉え直すこと** を目指しています。  
数値化は外部に伝えるためだけでなく、創作者自身が自らの言葉の揺らぎを見つめ直すための装置でもあります。  
戯画的に言えば、詩人の感覚（勘）に測定装置（計器盤）を接続する方法の開発を試みています。

## 詩的跳躍度（Divergence）の定義

各詩行ベクトル `x_i` と参照ベクトル `ref_i` のコサイン類似度に基づき、次のように定義します：

$$
D_i = 1 - \cos(x_i, ref_i)
$$

* **値域：0 ～ 2**
  * 完全に似ていれば 0
  * 直交すれば 1
  * 正反対なら 2

参照ベクトル `ref_i` は読者体験をモデル化し、逐次ローカル基準（-k行、すなわち過去方向の平均）を採用しています。  
（単一モデル版では k を任意に設定可能、４モデル比較版では k=3 に固定。）



> **コサイン類似度とは？**  
> 二つのベクトルが成す「角度」の近さを測る尺度。  
> 値域は **-1 ～ +1**。+1 なら完全に同じ方向、0 なら直交、-1 なら正反対。  
> 文献学や自然言語処理では、文章や語の意味的な近さを測定する手法として広く使用されているものです。  
> 数学的には単なる角度の計算ですが、詩に適用すると──  
> 「角度の隔たり」がそのまま意味の飛躍や余白となり、**Divergence** はそれを **跳躍の強度** として可視化します。  
> つまり、**詩が常に“正解のない飛躍”として生まれること**を示す指標です。

## セッションとデータ保持

* **アップロードされた詩行データはセッション内でのみ利用され、終了時に保持されません。**
* 利用者の入力は永続的に保存されることはありません。

---

## APIキーについて

* **OpenAI Embeddings 使用時は API Key が必須** です。
  * secrets → 環境変数 → 入力 UI の順に探索します。
  * セッション中のみ保持され、終了時に揮発します。

* Hugging Face Hub Token は任意ですが、Ruri 系モデル利用時に推奨されます。

## アプリの使い方（概要）

1. **詩行を入力またはアップロード**
   * テキストボックスに直接入力、または `.txt` / `.docx` ファイルをアップロード。

2. **モデルを選択**
   * サイドバーから SBERT / OpenAI / Ruri を選択。
   * 「４モデル比較版」ではすべてのモデルが同時に走ります。

3. **波形を確認**
   * 各詩行の Divergence が折れ線グラフとして描画されます。

4. **データを保存**
   * CSV ダウンロードボタンから結果を保存可能。
   * 「４モデル比較版」では **wide形式 CSV** が出力されます。
